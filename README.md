# konst-site — личный сайт Константина Сухарникова

**Статус:** черновик от 2026-11-09, **не опубликован**. Git — локально с 10.11.2026, на GitHub будет `KonstSu/konst-su.fyi` (см. «Перед публикацией»).

**Для агентов (Claude Code и др.):** все правила, факты, дизайн-система, рецепты и шаги публикации — в [`AGENTS.md`](AGENTS.md) (`CLAUDE.md` его подключает). Репозиторий самодостаточный: другие репозитории к сессии прикреплять не нужно. Исключение — генератор Science & Space читает соседние папки explorer'ов (только чтение).

Визитка, проекты, CV и форма обратной связи, плюс раздел **Science & Space**: обзор межпланетных миссий и больших научных установок из `space-explorer` и `science-explorer`. Статичный HTML/CSS, без сборщиков и сторонних скриптов. Язык сайта английский (British spelling, как в CV master).

`assets/css/style.css` — всё оформление. `assets/js/contact.js` — форма (переживает HTML-ответы Web3Forms), `calendar.js` — фильтр календаря, `science.js` — обратный отсчёт, фильтры и поиск по карточкам. `retro.js` — часы в строке меню и «Last modified» в футере. Шрифты JetBrains Mono (текст) и VT323 (крупные заголовки) лежат в `assets/fonts/` (OFL), к Google ничего не подключается. `assets/img/` — портрет, два фото HED и два фото бетатронов со старого сайта (EXIF удалён, оригиналы хранятся вне репозитория). Остальные фото устройств со старого сайта удалены из репозитория 10.11.2026, до первого коммита. Новые фото — только через `tools/prepare_photo.py`.

`.github/workflows/pages.yml` — автодеплой на GitHub Pages: при каждом push в `main` запускает `check_site.py --dist` и выкладывает только `dist/`. `tools/`: `build_science.py` — генератор Science & Space; `check_site.py` — проверка перед публикацией и сборка папки для выгрузки `dist/`; `layout_check.html` — вспомогательная страница для проверки вёрстки; `prepare_photo.py` — уменьшить фото, повернуть по EXIF, удалить метаданные.

## Оформление
Ретро-тема (с 2026-11-08): панели Norton Commander (синий фон, двойная рамка, заголовок на рамке, бирюзовая строка меню с часами, полоса F-клавиш 1–10 внизу: Home, About, Projects, CV, Skills, Papers, Explore (= Science & Space), Contact, Privacy, Top), чёрные «терминальные» зоны в духе CCRU, строка DOS-пути с курсором (`C:\KS\SCIENCE\MISSIONS\HAYABU~1.HTM>`), неоновая хроматическая аберрация на крупных заголовках, лёгкие CRT-сканлайны, значки 88×31 и «Last modified» в футере. Палитра — 16 цветов CGA/VGA, токены в начале `style.css`; синие панели переопределяют токены (`--text`, `--link`, `--label` …). Мигание курсора и «глитч» отключаются при `prefers-reduced-motion`; для печати (CV) тема сбрасывается в чёрное на белом.

Шапка, строка пути, футер и F-клавиши написаны прямо в корневых страницах и продублированы в `page()` в `tools/build_science.py`: меняешь меню — меняй в обоих местах.

## Просмотр и проверка
```bash
cd konst-site
python3 -m http.server 8770            # http://127.0.0.1:8770
python3 tools/check_site.py            # ссылки, якоря, CSP, картинки и метаданные, запрещённые формулировки, пометки
python3 tools/check_site.py --layout   # плюс горизонтальная прокрутка на 360/390/1440 px (headless Chrome)
python3 tools/check_site.py --dist     # строгая проверка и сборка dist/ — только эту папку выгружать
```
Публичные файлы — корневые `*.html`, `assets/`, `science/`. Всё остальное (README, AGENTS.md, `content/`, `data/`, `tools/`) — исходники, на хостинг не идут. `--dist` не соберётся, пока есть ошибки, жёлтые пометки или заглушка ключа формы; `--dist --allow-todo` — только для приватного предпросмотра.

## Science & Space
Страницы: Overview (Next up с отсчётом, «Where they fly» от Солнца до пояса Койпера, установки по стадиям, свежие результаты, ближайшие события), Missions (18 карточек с фильтрами и поиском), Facilities (31, с 09.11.2026 вместе с синхротронами), отдельная страница у каждой миссии и установки, Calendar, Results, Launches, Method.

Раздел подан как моё хобби: «science and space enthusiast» (09.11.2026). На каждой странице раздела есть строка «A hobby. … by a science and space enthusiast. I am not involved in these missions or facilities…», внизу — блок об авторе со ссылками на Projects и CV. На страницах миссий есть плашка «Not affiliated with …». European XFEL помечен «Where I work»: я там работаю, но страница не говорит от имени компании.

**Откуда данные.** Источник — русские карточки в соседних репозиториях; их агенты, `/digest` и локальные дашборды не трогаются:
- `../space-explorer/` — `missions/*.md`, `calendar.md`, `launches.md`;
- `../science-explorer/` — `facilities/*.md`, `calendar.md`, `results/<год>.md`.

Из исходников берутся структурные поля: `status`, `region`, `domain`, `launch_date`, `official`, а также календарь. Тексты лежат в английском слое этого репозитория:

| Путь | Что |
|---|---|
| `content/missions/<id>.md`, `content/facilities/<id>.md` | Перевод карточки: Summary, Now, Key dates, Results, Timeline, Links; во фронтматтере `tagline` и `next_event` |
| `content/results.md`, `content/launches.md` | Результаты и запуски |
| `content/method.md` | Как сделан раздел (страница Method) |
| `data/calendar.json` | Переводы строк календаря, исключения, ссылки на конференции |

**Обновление после `/digest`:**
```bash
python3 tools/build_science.py --check     # что изменилось и что требует перевода (ничего не пишет)
python3 tools/build_science.py             # собрать science/ и блок на index.html
```
- Каждый английский файл хранит хэш русского исходника (`source_hash`) и дату (`checked`). Если `/digest` поменял только `last_checked`, ничего делать не нужно: на странице просто обновится дата «as of».
- Если текст карточки изменился, `--check` пишет `stale`. Сайт при этом показывает прежний английский текст со старой датой «as of», без смеси языков. Попросить Claude: «обнови английские карточки, которые stale, и пересобери». После правки перевода выполнить `python3 tools/build_science.py --stamp europa-clipper` (или `--stamp all`).
- Новая карточка в explorer'е без английского файла на сайт не попадает, `--check` о ней сообщает.
- Новые строки календаря скрипт добавляет в `data/calendar.json` с пустым переводом и не показывает, пока их не перевели. Для строк без ссылки на карточку перевод пишется как `Title: text`.
- Запланированное событие с прошедшей датой не считается состоявшимся: оно уходит в Recently с пометкой «outcome not yet confirmed».
- **`data/private.json` — только локально, в git не попадает** (решение 10.11.2026). В нём правила, которые сами выдают непубличную информацию European XFEL: какие строки календаря никогда не публикуются и какие термины и коды `check_site.py` не пропускает на страницы. Без этого файла генератор ничего не собирает (код 2), `check_site.py` предупреждает. **Храни свою копию** (например, в заметках): из git его не восстановить. `exclude` в `data/calendar.json` — только для правил, которые ничего не выдают.
- Если соседних папок explorer'ов нет, генератор останавливается с кодом 2 и `science/` не трогает.
- При переводе убираются внутренние пометки («сверить», «задача на следующий выпуск»), ссылки на `phd/` и сайты-агрегаторы. Оговорки, нужные читателю, остаются: «sources differ», «not yet confirmed».
- Разделы PhD и дайджесты explorer'ов на сайт **не выводятся**.
